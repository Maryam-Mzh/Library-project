# 📚 Python Library Management System

A beginner-friendly Python project implementing modules, packages, and local `pip` installation, created as a first step into version control and GitHub.

---

## 🚀 Features

### 1. Library Module (`library.py`)
Includes a `Library` class with the following methods:
* **`add_book(title, author)`**: Adds a new book to the library inventory.
* **`remove_book(title)`**: Removes a book by its title.
* **`search_book(title)`**: Searches for books matching the given title.
* **`show_books()`**: Displays all available books in the library.

### 2. Interactive Menu (`main.py`)
* Implements `if __name__ == "__main__":` to check if the script is run directly.
* Provides a simple interactive console menu to add, remove, search, and view books.

### 3. Local Package Installation (`pip install`)
* Structured inside a `mylibrary` directory with an `__init__.py` file.
* Includes a `setup.py` configuration file.
* Can be installed locally using:
  ```bash
  pip install .
